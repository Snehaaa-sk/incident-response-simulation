# incident-response-simulation
Incident Response Simulation project completed during my Cyber Security Internship at InternPe. Demonstrates detection, analysis, containment, and recovery of unauthorized login attempts using Windows Event Viewer.

Overview
This project demonstrates a basic Incident Response (IR) simulation using Windows Event Viewer. The objective was to simulate unauthorized login attempts, detect suspicious authentication activity, investigate security logs, and perform incident response procedures including detection, analysis, containment, eradication, and recovery.

This project was completed as Assignment #3 during my Cyber Security Internship at InternPe.

Objective

Simulate an unauthorized access attempt.
Monitor Windows Security Logs.
Detect failed authentication events.
Investigate suspicious login activity.
Perform root cause analysis.
Document incident response procedures.

Environment
Operating System
Windows 11

Tools Used
Windows Event Viewer
Windows Security Logs
Windows Authentication System

Incident Scenario
A controlled security event was generated by intentionally entering incorrect credentials multiple times on the Windows login screen.

Steps Performed
Opened Windows Event Viewer.
Navigated to Windows Logs → Security.
Locked the system using Windows + L.
Entered incorrect credentials multiple times.
Logged in successfully using valid credentials.
Investigated generated security events.

Detection & Analysis
Event ID 4625 – Failed Login Attempt
Detected multiple Event ID 4625 entries indicating failed authentication attempts.

Findings:
Event ID: 4625
Category: Logon
Keyword: Audit Failure
Source: Microsoft Windows Security Auditing

Investigation Findings
Observations
Multiple failed login attempts detected.
Authentication failures occurred within a short timeframe.
No evidence of unauthorized access.
Activity originated from the local system.

Timeline
Time	Event ID	Description
12:30:14	4625	Failed Login Attempt
12:30:20	4625	Failed Login Attempt
12:30:25	4625	Failed Login Attempt
12:32:22	4624	Successful Login

Containment
Actions Taken:
Reviewed login activity.
Verified account legitimacy.
Monitored authentication attempts.
Confirmed no unauthorized access occurred.

Eradication
Actions Taken:
Verified incident was part of a controlled simulation.
Confirmed no malware activity.
Confirmed no unauthorized user accounts existed.

Recovery
Event ID 4624 – Successful Login
A successful authentication event was detected after entering valid credentials.

Findings:
Event ID: 4624
Category: Logon
Keyword: Audit Success

Root Cause Analysis
Root Cause
Repeated incorrect password entries generated failed authentication events within the Windows Security Log.

Impact
No system compromise
No malware execution
No unauthorized access
No data loss
Risk Level: Low

Lessons Learned
Security logs provide valuable forensic evidence.
Failed authentication attempts can indicate attack activity.
Continuous monitoring improves detection capabilities.
Proper documentation strengthens incident response readiness.

Recommendations
Enable Multi-Factor Authentication (MFA)
Enforce strong password policies
Configure account lockout policies
Monitor authentication logs regularly
Implement centralized log monitoring using SIEM solutions

Conclusion
This project successfully demonstrated the Incident Response lifecycle through the simulation of unauthorized login attempts. Security events were detected, investigated, analyzed, and documented using Windows Event Viewer, providing practical experience in log analysis, threat detection, and incident response.
